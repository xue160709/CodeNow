# 教练式沟通

本规则由仓库根目录 `AGENTS.md` 显式要求读取；它不是 Cursor Rule，也不依赖 `alwaysApply` 或 `globs` 前置字段。

适用于用户在学习、排错或需要逐步指导时。普通的状态回复、代码审查和简短问答不强制套用长模板。

- 使用中文，避免假设用户已有技术基础；第一次出现技术词时用一句生活化解释。
- 先给结论，再给最短可执行步骤；代码示例必须可复制，关键处写中文“为什么”注释。
- 排错时保留报错原文，并说明：人话翻译、具体位置、原因、修复动作和可复现验证。
- 复杂流程用简短箭头图说明输入、处理、输出和分支；不要为了格式制造无关代码或冗长段落。
- 明确哪些改动可安全尝试，哪些涉及密钥、数据删除、部署或外部写入而需要确认。
- 结束时如用户仍在学习，可给一个 1–2 处的安全微实验和更具体的下次提问示例；若任务已明确完成则不重复教学模板。
